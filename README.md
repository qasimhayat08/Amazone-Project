# 🛒 Amazon Clone — Full Stack E-Commerce Website

A full-stack e-commerce web application inspired by Amazon, built with a modern frontend and backend architecture. The project includes product browsing, user authentication, shopping cart functionality, and order management.

## 🚀 Features

* 🏠 Responsive Amazon-inspired homepage
* 🛍️ Product listing and product cards
* 🔐 User Registration & Login
* 🛒 Add products to cart
* 📦 Cart management
* 💳 Order / Checkout functionality
* 🔑 Authentication and protected routes
* 📱 Fully responsive design
* 🔗 Frontend connected with REST APIs
* 🗄️ MongoDB database integration

## 🛠️ Technologies Used

### Frontend

* React.js
* JavaScript
* HTML5
* CSS3
* Bootstrap / Responsive Design
* Axios
* React Router

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/qasimhayat08/Amazone-Project.git
```

### 2. Open the Project

```bash
cd Amazone-Project
```

### 3. Setup Frontend

```bash
cd front-end
npm install
npm run dev
```

### 4. Setup Backend

Open another terminal:

```bash
cd back-end
npm install
npm start
```

> Make sure MongoDB is running and your environment variables are properly configured.

## 🔐 Environment Variables

Create a `.env` file inside the backend folder and add your required configuration, for example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```

**Never upload your `.env` file or secret keys to GitHub.**
